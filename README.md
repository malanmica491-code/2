# กระดานสนทนา นศท. — วางขึ้น Netlify

โครงสร้าง
- `public/index.html`  หน้าเว็บทั้งหมด
- `netlify/functions/api.mjs`  หลังบ้าน (ข้อมูลเก็บใน Netlify Blobs ไม่ต้องตั้งค่าฐานข้อมูล)
- `netlify.toml`, `package.json`

## วางขึ้น Netlify
1. อัปโหลดโฟลเดอร์นี้ทั้งหมดขึ้น GitHub แล้ว Netlify จะ deploy ให้เอง (ต้องใช้ Git หรือ Netlify CLI ลากวางไม่ได้)
2. เปิดเว็บ แล้ว "สร้างบัญชีใหม่" — บัญชีแรกจะได้เป็นผู้ดูแลทันที (ไม่ต้องใช้รหัสลับ ตัวแปร ADMIN_CODE ไม่ใช้แล้ว ลบทิ้งได้)

## เปิดระบบยืนยันอีเมล Gmail (ไม่บังคับ)
ถ้ายังไม่ตั้งค่า ระบบจะข้ามขั้นยืนยันอีเมลตอนสมัคร และยังเพิ่มอีเมลทีหลังไม่ได้
ตั้งค่า 2 ตัวแปรที่ Netlify → Site configuration → Environment variables แล้ว Deploy ใหม่:
- GMAIL_USER = อีเมล Gmail ที่ใช้ส่งรหัส (เช่น mycamp.forum@gmail.com)
- GMAIL_APP_PASSWORD = รหัสผ่านแอป 16 ตัวของบัญชีนั้น
  (เปิดการยืนยัน 2 ขั้นตอนของบัญชี Google ก่อน แล้วไปที่ myaccount.google.com/apppasswords สร้างรหัสผ่านแอป)

รหัสที่ส่งเป็นตัวอักษร+ตัวเลข 6 ตัว (พิมพ์เล็ก/ใหญ่ต่างกัน) หมดอายุ 30 วินาที ขอใหม่ได้ทุก 10 วินาที
